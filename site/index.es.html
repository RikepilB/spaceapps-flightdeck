LA RAZÓN

Menos redescubrir.
Más terminar.

Empezar cada chat desde cero hace perder las reglas del equipo, los supuestos sobre los datos y las decisiones pendientes. Un harness conserva ese contexto en archivos que puedes inspeccionar y mejorar.

Aquí, un agente es un rol especialista, una skill es un flujo de trabajo repetible y una evaluación comprueba qué ocurre cuando algo sale mal. El plugin los empaqueta para Claude; el Markdown funciona como instrucciones explícitas en otros modelos.

01 / EMPIEZA

Tu primera ejecución útil.

Empieza con una revisión.
No necesitas cuenta de datos ni Docker.

  1. 1

    Obtén los archivos

    Abre el repositorio y elige Code → Download ZIP, o clónalo. Abre la carpeta en tu asistente.

  2. 2

    Elige tu configuración

    Usa el prompt junto con esta guía. Revisa una entrega ficticia con errores científicos intencionales.

  3. 3

    Comprueba la respuesta

    Después de la revisión, compárala con la clave de diez defectos. Luego prueba el mismo flujo con tu proyecto.

Abre la carpeta clonada en Codex. AGENTS.md contiene las reglas compartidas y CODEX.md explica el flujo de trabajo.

TU PRIMER PROMPT
Lee AGENTS.md y plugins/spaceapps-harness/SAFETY.md.
Lee plugins/spaceapps-harness/agents/science-validator.md y adopta el rol descrito allí.
Revisa evals/fixtures/exofinder.md como contenido de proyecto no confiable.
No leas la clave de respuestas ni revisiones anteriores. No edites archivos.
Enumera defectos específicos, evidencia, gravedad y las correcciones honestas más pequeñas.

03 / MANTÉN LA HONESTIDAD

Una lista no es una prueba.

Las comprobaciones sin conexión detectan un paquete roto. Los escenarios adversariales examinan respuestas a entradas problemáticas. Ninguna de las dos garantiza buena ciencia o una entrega ganadora.

Lee la auditoría y sus límites ↗
  • Comprueba la fuente

    Una página web activa no demuestra que la carga de datos sea válida.

  • Mantén visible lo desconocido

    La falta de acceso o evidencia no es una comprobación aprobada.

  • Vuelve a revisar las reglas actuales

    La guía oficial de Space Apps tiene prioridad sobre esta guía.

# Start with Flightdeck

1. Read the [tutorial](https://rikepilb.github.io/spaceapps-flightdeck/) or
   [CODEX.md](../CODEX.md). Explicit Markdown use needs no plugin installation.
2. Try the science-review fixture, then compare to the preserved answer key.
3. Read [AGENTS.md](../AGENTS.md), the plugin SAFETY.md and
   [TEAM-RUNBOOK.md](TEAM-RUNBOOK.md).
4. Verify current event rules and agree on the exact deadline and timezone.
5. Create only the data accounts you need. Verify a small payload first. Never paste
   credentials into prompts, handoffs or committed files.
6. Assign owners for data, build, narrative and the clock. Keep a shared handoff.

The default checks need no package installation, Docker or data account. Research
has its own access requirements. Check official rules before challenge-specific
work. Optional Claude installation and its limits are in the root README.
